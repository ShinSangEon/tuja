# 04. 어디가 유료인가 — 비용 정리 (2026-10 기준, 수동 추출 · GENEQ 계정의 Neon/Vercel/카카오)

> 요금은 바뀐다. "확인처"에서 한 번 더 본다. 금액은 **이 시스템의 예상 사용량** 기준.

## 한 줄 요약

**확실히 나가는 돈은 Vercel 하나.** 추출은 Claude 세션에서 수동(API 미사용), 데이터 소스는 전부 무료, Neon·카카오는 무료 플랜 안. Vercel 은 회사 용도라 Pro(월 $20) 가 정석.

## 주의 두 가지

1. **카카오맵 무료 쿼터는 "개발자 계정당 첫 번째로 활성화한 앱"에만** 붙는다. GENEQ 카카오 계정을 새로 만들어 첫 앱으로 활성화하면 깔끔하게 무료 쿼터 대상이 된다. 비즈 앱 전환에 사업자등록번호가 필요하고 심사 1~3일.
2. **Vercel Hobby 는 비상업 용도 한정**. GENEQ 계정이면 회사 용도가 명확하니 Pro 로 가는 게 맞다. 월 $20 이 아까우면 같은 코드를 사내 PC 에서 `npm start` 로 띄워도 된다 (0원, 사내망에서만 접속).

## 나중에 자동화하고 싶어지면

Claude API 로 추출을 자동화할 때 드는 돈만 추가된다: 하루 50문서 × 3~4천 토큰 기준 **월 2~5만 원** (소형 모델 1차 분류 + 상위 모델 추출). `extract.py` 의 INSTRUCTIONS 가 그대로 시스템 프롬프트가 되므로 전환은 반나절 작업.
